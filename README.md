# NovaTool AI

A security-first, privacy-friendly collection of free browser-based tools.

## Current tools
- Calculator
- Unit Converter
- Word Counter
- QR Generator
- Password Generator
- Case Converter
- Local text summarizer
- Local text cleaner/rewriter
- Secure placeholder for future AI Chat integration

## Security principles
- No payment system
- No API keys in frontend code
- Minimal data collection
- Browser-first processing where possible
- Security headers configured in `vercel.json`

## Run locally
```bash
npm install
npm run dev
```

This project is designed to be portable between hosting providers.
